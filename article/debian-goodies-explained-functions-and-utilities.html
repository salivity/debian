Debian-Goodies Explained: Functions and Utilities

The debian-goodies package is a curated suite of lightweight, command-line utilities designed to supplement Debian’s native package management ecosystem. While standard tools like APT and dpkg handle core package operations, debian-goodies provides system administrators and users with specialized scripts to diagnose system states, inspect packages, and streamline everyday maintenance. This article outlines the primary function of debian-goodies and details the specific utilities it adds to the Debian operating system.

Core Function of debian-goodies

In Debian, many small, single-purpose administrative scripts are too minor to justify individual package distribution. The debian-goodies package bundles these standalone tools into a single, cohesive installation. Its primary function is to extend package auditing, disk space management, and troubleshooting capabilities without adding heavy software dependencies. It bridges the gap between low-level dpkg queries and high-level system inspection.

Key Utilities in debian-goodies

Once installed via standard repository managers (sudo apt install debian-goodies), the package provides several dedicated commands:

  • checkrestart: Scans the system for processes that are still using old, deleted versions of libraries or executables. This is especially useful after running security updates, as it identifies which background daemons need to be restarted without requiring a full system reboot.
  • dpigs: Displays the packages consuming the most disk space on the system. By default, it lists the top ten largest packages, making it an essential tool for clearing out unnecessary storage use. It supports flags to adjust the count or inspect source packages.
  • which-pkg-broke: Analyzes package dependencies to help identify which recently upgraded package may have broken another. It lists the dependencies of a target package along with their installation and modification times.
  • debman: Retrieves and displays manual pages from packages without requiring the packages themselves to be installed on the local system. It downloads the target package momentarily, extracts the man page, and presents it to the user.
  • debmany: Provides an interactive text-based interface to select and read all available documentation and man pages included within a specific installed or uninstalled Debian package.
  • dglob: Generates a list of package names that match a specified pattern, functioning as a fast alternative to running complex regular-expression pipelines through dpkg -l.
  • dhomepage: Queries package metadata and prints or opens the official upstream homepage URL of a specified package in a web browser.
  • check-enhancements: Searches for installed or available packages that provide enhancements for packages currently installed on the system, utilizing the "Enhances" control field.

By integrating these utility scripts, debian-goodies simplifies routine system monitoring, enhances package visibility, and speeds up diagnostic tasks on any Debian-based distribution.
