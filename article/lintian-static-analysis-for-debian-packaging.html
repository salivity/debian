Lintian Static Analysis for Debian Packaging

Lintian is the definitive static analysis tool used in the Debian operating system to verify that software packages conform strictly to Debian packaging standards. By parsing binary and source packages without executing them, Lintian identifies policy violations, structural bugs, security flaws, and common packaging mistakes. It acts as an automated quality assurance checkpoint, ensuring that tens of thousands of individual packages maintain uniform behavior, stability, and system integration across the entire Debian ecosystem.

Enforcing the Debian Policy Manual

The Debian Policy Manual defines the rigorous technical requirements that every package in the archive must satisfy. Because manually auditing thousands of packages against this documentation is impractical, Lintian automates the process. It inspects:

  • File Hierarchy Standards (FHS): Verifies that binaries, configuration files, libraries, and documentation are installed into their proper directories.
  • Control Metadata: Ensures package dependencies, descriptions, maintainer scripts, and architectural declarations are valid and syntactically correct.
  • Licensing and Copyright: Checks that copyright statements, licenses, and machine-readable metadata align with Debian Free Software Guidelines (DFSG).
  • Security Practices: Scans maintainer scripts for insecure temporary file usage, flawed shell logic, unsafe file permissions, and missing compiler hardening flags.

Issue Classification and Tagging

When Lintian scans a package, it outputs a report composed of specific "tags." These tags categorize potential issues by severity and certainty:

  • Errors (E): Direct violations of strict Debian Policy or critical bugs that typically make a package unsuitable for release.
  • Warnings (W): Probable violations, major recommendations, or packaging anomalies that maintainers should investigate and fix.
  • Info (I): Informational notes regarding best practices, minor inconsistencies, or emerging policy changes.
  • Pedantic (P): Extremely strict suggestions regarding packaging polish and stylistic conformity.
  • Experimental (X): Tests for new or evolving checks that may produce false positives.

Workflow Integration and Archive Quality Control

Lintian is deeply embedded into the Debian developer toolchain. Package maintainers run Lintian locally during the build phase using wrappers like debuild or continuous integration systems such as sbuild.

Beyond the developer's workstation, Lintian serves as a gatekeeper for the official archive. When a package is uploaded to the Debian archive software (DAK), Lintian scans the package automatically. Severe policy breaches can trigger an automatic rejection, preventing broken packages from reaching testing and unstable repositories.

Overrides for Justified Exceptions

Debian recognizes that certain edge cases require deliberate deviations from standard policy. To handle these scenarios without generating false alarms, Lintian supports "overrides." A maintainer can place a designated text file inside the package containing specific Lintian tags alongside clear, documented explanations for why the exception is acceptable. These overrides are reviewed by Debian archive administrators, striking a balance between strict automation and practical flexibility.
