Debian Package Tracker: How tracker.debian.org Works

This article provides an overview of tracker.debian.org, the central package tracking service for the Debian operating system. It details the platform's primary functions, the critical technical data it aggregates, and how Debian maintainers, contributors, and end-users utilize it to monitor software packages across Debian's different distribution branches.

Centralized Package Metadata and Status

The primary function of tracker.debian.org is to act as a unified dashboard for every source package available in the Debian archive. Instead of requiring users to query multiple distinct infrastructure services, the tracker aggregates real-time data into a single web interface.

Key information provided for each package includes:

  • Archive Versions: The exact version of the package currently present in each Debian suite: Experimental, Unstable (Sid), Testing, Stable, and Oldstable.
  • Package Relations: Identification of the package maintainer, co-maintainers, Debian teams, and links to the upstream project's source repositories and version control systems (such as Salsa/GitLab).
  • Architecture Availability: Build status across all supported hardware architectures (e.g., amd64, arm64, riscv64), linking directly to Debian's automated build daemon network (buildd).

Testing Migration Monitoring

For Debian contributors and users awaiting updates, the tracker serves as the primary tool to monitor "testing migration." It displays the output of the Britney migration script, which determines when a package can move from Unstable to Testing.

The tracker explicitly lists:

  • The age requirements of the package in Unstable.
  • Passing or failing autopkgtest results.
  • Dependency blockers or missing builds on specific architectures.
  • Release-critical bugs that are preventing the package from advancing.

Bug Tracking and Security Integration

The tracker links directly with the Debian Bug Tracking System (BTS) and the Debian Security Team's resources. It provides a real-time count and classification of outstanding issues, including:

  • Release-Critical (RC) Bugs: Flaws that can prevent a package from being included in the next stable Debian release.
  • General Bugs: Regular, minor, and wishlist bug counts.
  • Security Advisories: CVE notices, security vulnerabilities, and direct links to Debian Security Advisories (DSAs) relevant to that specific codebase.

Communication and Subscription System

Beyond displaying static data, tracker.debian.org operates a granular subscription service via email. Maintainers, downstream distributors, and interested end-users can subscribe to specific package feeds to receive notifications regarding:

  • New package uploads and changelogs.
  • BTS bug activity (new bugs opened, tagged, or closed).
  • Build failures reported by buildd.
  • Lintian QA warnings and automated code review issues.
  • Package adoption, orphaned status, or removal notices.
