Officially Supported Debian Release Architectures

Debian is renowned for its portability across a wide variety of hardware platforms, referring to itself as "the universal operating system." This article provides a comprehensive overview of the computer architectures officially qualified as release architectures in the current stable version of the Debian operating system, detailing what platforms are fully supported by Debian's security updates and installation media.

Understanding Debian Release Architectures

In the Debian ecosystem, a port must meet strict requirements to be designated as an official "release architecture." These criteria include having a functional, redundant build daemon (buildd) infrastructure, active maintenance, a working Debian Installer, and full integration with Debian’s security tracking and archive management tools. Architectures that do not meet these criteria are relegated to "Debian-Ports," where they are maintained outside the main release archive.

Officially Supported Architectures in Current Debian Stable

As of Debian 12 ("Bookworm"), the Debian project officially supports nine architectures across personal computers, enterprise servers, and embedded devices:

  • amd64 (64-bit PC / x86-64): The most common architecture for modern desktop computers, laptops, and enterprise servers using Intel and AMD 64-bit processors.
  • arm64 (64-bit ARM / AArch64): Designed for modern 64-bit ARM processors, widely found in cloud servers, single-board computers, and modern mobile and embedded hardware.
  • armel (EABI ARM): Targets older 32-bit ARM processors (specifically ARMv5te and above) that utilize soft-float emulation.
  • armhf (ARM Hard Float): Designed for 32-bit ARM processors (ARMv7 and later) that include hardware floating-point units, common in devices like earlier Raspberry Pi models and various development boards.
  • i386 (32-bit PC / x86): Covers legacy 32-bit Intel and AMD processors. While primarily used today for legacy applications and multiarch compatibility, it remains an official architecture.
  • mips64el (64-bit MIPS Little-Endian): Supports 64-bit MIPS processors operating in little-endian mode, typically used in embedded devices, routers, and specific server platforms.
  • mipsel (32-bit MIPS Little-Endian): Supports legacy 32-bit MIPS hardware running in little-endian mode.
  • ppc64el (64-bit PowerPC Little-Endian): Tailored for 64-bit IBM POWER processors using the OpenPOWER Little-Endian ABI, commonly deployed in enterprise-grade data centers.
  • s390x (IBM System z / z/Architecture): Built for 64-bit IBM mainframes, providing enterprise-level server support for legacy and modern computing tasks.

Upcoming Changes in Future Releases

The list of official architectures changes based on hardware relevance, upstream kernel support, and maintainer availability. For future releases (beginning with Debian 13 "Trixie"), support for older architectures such as mipsel and armel has been phased out, while support for newer architectures, such as riscv64 (64-bit RISC-V), has been integrated into the official release cycle.
