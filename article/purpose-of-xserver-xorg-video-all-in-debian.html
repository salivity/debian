Purpose of xserver-xorg-video-all in Debian

The xserver-xorg-video-all package in Debian is a metapackage designed to ensure complete out-of-the-box display hardware compatibility for the X.Org graphical server. Rather than containing driver software itself, it depends on a comprehensive collection of open-source video driver packages for virtually all common graphics hardware. This article explains how this metapackage functions, which drivers it pulls into the system, and why it is used during standard Debian desktop installations.

What Is a Metapackage?

In Debian, a metapackage contains no executable code, libraries, or configuration files of its own. Instead, it consists purely of package metadata—specifically a dependency list. When you install a metapackage, the Debian package manager (apt or dpkg) reads these dependencies and automatically installs all the targeted software components linked to it.

The Core Purpose of xserver-xorg-video-all

The primary role of xserver-xorg-video-all is to guarantee that the X Window System (Xorg) can start successfully on any computer, regardless of its graphics card, without requiring user intervention.

When the Debian installer sets up a desktop environment, it typically does not know the exact graphic hardware configurations a user might run in the future. By installing xserver-xorg-video-all, Debian installs free and open-source video drivers for all supported architectures at once. This automatic fallback capability ensures that if a system is booted on different hardware—or if the GPU is upgraded—the display server can detect the device and render the graphical desktop immediately.

Drivers Included in the Metapackage

Depending on the hardware architecture (such as amd64 or i386), xserver-xorg-video-all depends on the following standard open-source display drivers:

  • xserver-xorg-video-amdgpu: Supports modern AMD/Radeon graphics cards.
  • xserver-xorg-video-ati: Supports legacy ATI and older Radeon GPUs.
  • xserver-xorg-video-intel: Legacy 2D driver for Intel integrated graphics.
  • xserver-xorg-video-nouveau: Open-source driver for NVIDIA graphics cards.
  • xserver-xorg-video-qxl: Driver optimized for QEMU/KVM virtualized desktop environments.
  • xserver-xorg-video-vmware: Driver designed for VMware virtual machines.
  • xserver-xorg-video-vesa: Generic driver that provides fallback display functionality for almost any PC-compatible GPU when native acceleration drivers fail.

Relevance in Modern Debian Systems

In modern versions of Debian, the Xorg server often defaults to the generic, built-in modesetting driver, which relies on kernel-mode setting (KMS) implemented directly inside the Linux kernel. This has reduced the necessity for specific user-space DDX drivers, especially for Intel and newer AMD chipsets.

Despite this shift, xserver-xorg-video-all remains a standard component in desktop task installations (such as task-desktop). It acts as a safety net for legacy hardware, virtual machines, and configurations where the generic modesetting driver is not optimal or supported.

Can It Be Removed?

Yes. If a user wants to minimize disk space or streamline installed packages on a system with static hardware, xserver-xorg-video-all can be removed safely. Removing the metapackage does not automatically delete the individual driver packages unless an autoremove command is issued. As long as the specific driver required by the system's GPU (or the modesetting driver) remains installed, the graphical environment will continue to work normally.
