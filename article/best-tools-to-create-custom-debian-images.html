Best Tools to Create Custom Debian Images

Debian provides a flexible ecosystem for generating custom operating system images suited for embedded devices, virtual machines, cloud instances, and live environments. This article covers the most effective and widely used tools available directly within the Debian operating system for assembling tailored Debian-based root filesystems and bootable media.

1. debootstrap and mmdebstrap

debootstrap is the foundational utility used to install a Debian base system into a target directory. It downloads essential .deb packages directly from a Debian repository and unpacks them, creating a clean root filesystem (chroot) without requiring an active installer.

mmdebstrap is a modern, faster alternative to debootstrap. It can create root filesystems without requiring superuser privileges (rootless mode using user namespaces) and offers multiple output formats, such as tarballs, squashfs images, or directory trees.

2. Live-build

live-build is the official suite of tools used by the Debian Live project to create complete live systems. Configured through a set of scriptable directories and configuration files, it can generate bootable ISOs, USB flash drive images, and netboot (PXE) configurations. It allows comprehensive customization of pre-installed packages, default desktop environments, user credentials, and kernel parameters.

3. vmdb2 (Virtual Machine Disk Builder 2)

vmdb2 is the successor to vmdebootstrap and is designed to create raw disk images for virtual machines and single-board computers (such as the Raspberry Pi). It operates using declarative YAML configuration files that specify partitioning schemes, bootloader installation (e.g., GRUB, U-Boot), filesystem formatting, and package deployment.

4. debos

debos is a modern, recipe-driven OS image builder developed in Go. It uses YAML files to orchestrate the creation of disk images, utilizing systemd-nspawn instead of standard chroot for isolation. debos supports caching, multi-architecture emulation via QEMU, and custom script execution, making it a common choice for continuous integration (CI) pipelines and embedded Linux development.

5. FAI (Fully Automatic Installation)

FAI is an enterprise-grade provisioning framework that automates the deployment of Debian systems. While primarily known for unattended network installations on bare metal, FAI includes tools like fai-cd and fai-diskimage to generate bootable installation media, cloud images, and container images based on simple class-based configuration profiles.

6. Elbe (Embedded Linux Build Environment)

Elbe focuses on deterministic and reproducible builds for embedded systems. It uses a single XML configuration file to define the target operating system. Elbe executes the build process inside an isolated virtual machine running under QEMU, ensuring that host system packages do not contaminate the generated target image or its software archive.
