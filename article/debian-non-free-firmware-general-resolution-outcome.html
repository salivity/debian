Debian Non-Free Firmware General Resolution Outcome

In October 2022, the Debian Project concluded a historic General Resolution vote regarding the inclusion of non-free firmware in official installation media. The Debian developer community decisively chose to amend the Debian Social Contract and officially bundle proprietary firmware packages with official installer and live images. This major policy shift resolved long-standing usability issues on modern hardware, officially taking effect with the release of Debian 12 ("Bookworm").

The Background of the Issue

For decades, Debian prioritized software freedom by strictly separating purely free software from proprietary components. While this adhered closely to the Debian Free Software Guidelines (DFSG), modern computer hardware—especially Wi-Fi adapters, graphics processors, and network cards—increasingly required closed-source binary blobs (firmware) just to operate.

Users faced severe installation hurdles because official Debian media lacked these proprietary drivers. To get hardware working, users had to search for unofficial, community-generated installer images that bundled non-free firmware. This caused widespread confusion, poor user experience, and fragmented maintenance efforts across the project.

The Vote and the Winning Option

To resolve the impasse, Debian developers held a General Resolution vote in late 2022 featuring six distinct proposals ranging from maintaining the strict status quo to fully endorsing non-free firmware.

The community selected Proposal E (Option 5), which passed with a substantial majority. This option enacted a balanced compromise between software freedom, transparency, and modern hardware support.

Key Outcomes of the Resolution

The resolution mandated several critical changes to Debian's distribution policy:

  1. Amendment to the Debian Social Contract: Point 5 of the Debian Social Contract was officially amended. It now includes explicit permission for hardware enablement:
    "The Debian official media may include firmware that is otherwise not part of the Debian system to allow use of Debian with hardware that requires such firmware."

  2. Creation of the non-free-firmware Archive Section: Debian created a dedicated archive component called non-free-firmware, cleanly separating hardware firmware binaries from other proprietary userland applications found in the broader non-free repository.

  3. Inclusion on Official Media by Default: Official Debian installation and live images now bundle necessary non-free firmware packages by default. When the installer detects hardware requiring proprietary firmware, it loads the necessary binary automatically to ensure smooth hardware initialization.

  4. User Transparency and Disabling Options: The installer actively notifies users whenever non-free firmware is loaded and logs that information on the target system. Users retain the ability to disable non-free firmware via boot parameters if they prefer a strictly free environment.

  5. Retention of Pure-Free Media: Debian committed to exploring and maintaining download options containing only free software for users who require a fully DFSG-compliant installation from the start.

The Practical Impact

The resolution removed one of the largest adoption barriers for the Debian operating system. Starting with Debian 12 ("Bookworm"), new installations automatically configure network hardware and peripheral components without requiring unofficial workarounds, modernizing Debian's setup process while maintaining explicit transparency about non-free code running on user systems.
