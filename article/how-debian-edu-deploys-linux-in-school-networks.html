How Debian Edu Deploys Linux in School Networks

Debian Edu, also known as Skolelinux, is a specialized Debian pure blend engineered to provide an instantly functional, pre-configured IT infrastructure for schools. By leveraging centralized network architecture, automated PXE boot installations, diskless client technologies, and unified directory services, Debian Edu enables system administrators to deploy and maintain dozens or hundreds of computers across a school campus with minimal manual intervention.

Modular Architecture and Installation Profiles

Debian Edu utilizes a profile-based system during installation that allows administrators to define the role of any machine on the network. Built around standard Debian packages, the distribution provides predefined profiles that configure necessary services automatically:

  • Main Server (Tjener): Acts as the network backbone, hosting core services such as LDAP directory management, Kerberos authentication, DNS, DHCP, Webmin/GOsa² administration tools, and Network File System (NFS) home directories.
  • LTSP Server: Hosts environments for diskless thin clients and diskless workstations.
  • Workstation: A standard PC with Debian installed on local storage that authenticates against the Main Server and accesses centralized user directories.
  • Roaming Workstation: Designed for laptops, enabling users to log in with school credentials while on campus and cache credentials for offline use outside school.
  • Standalone: An independent machine containing school software for environments without a permanent network connection.

Network-Based Automated Deployment (PXE)

To eliminate the need for manual physical installation via USB drives or optical discs, Debian Edu relies heavily on Preboot Execution Environment (PXE) network booting. Once the Main Server is operational, it serves as a DHCP and TFTP server.

When a bare-metal machine connects to the school network and boots from its network card, it receives an IP address and loads the Debian Edu boot menu over the local network. Administrators can deploy workstations automatically using Debian's automated installation framework (preseed files). These configuration files answer setup questions in advance, automating partitioning, desktop environment selection, repository configuration, and domain joining without requiring physical user input at each machine.

Thin Clients and Diskless Workstations via LTSP

For classrooms with aging hardware or environments requiring zero local maintenance, Debian Edu integrates the Linux Terminal Server Project (LTSP). This model eliminates the need to install an operating system on individual client hard drives:

  1. Thin Clients: The client computer boots a minimal Linux kernel via PXE, connects to an LTSP server, and renders a graphical session (such as XFCE) that physically executes on the server hardware. This drastically reduces hardware requirements for student machines.
  2. Diskless Workstations (Fat Clients): Modern systems download a full operating system image over the network into RAM and run software using local CPU and RAM resources, but store no persistent data on local drives. Operating system updates only need to be applied once to the central server image, automatically updating all client machines upon their next reboot.

Centralized Authentication and File Sharing

Debian Edu deploys an integrated user management structure using OpenLDAP and Kerberos. When any Debian workstation or client connects to the network, user authentication is handled centrally. A student or teacher can sit at any computer in the school, enter their credentials, and access their personalized desktop environment along with their centrally hosted NFS home directory.

Network-wide administration is handled through a web-based interface (GOsa²), allowing school staff to manage user accounts, group permissions, and system configurations across the entire fleet from a single browser session. This unified infrastructure ensures that once Debian is deployed, ongoing administrative overhead remains low.
